# Cron Job Setup Guide

> Generated by ChatGPT

This document explains how to set up and run the cron job for summarizing stale conversations on a VPS or server environment.

## 1. SSH into your VPS

```bash
ssh username@your-vps-ip
```

## 2. Install Python & dependencies

Make sure the Python version matches the project (Python 3.11 recommended).

```bash
# Optional: create a virtual environment
python3.11 -m venv venv
source venv/bin/activate

# Install project dependencies
pip install -r requirements.txt
```

## 3. Set required environment variables

```bash
export MONGODB_LOCAL_URL="mongodb://localhost:27017"
export OTHER_API_KEY="your_api_key_here"
```

Or use a `.env` file if your project supports it.

## 4. Test running the cron job manually

```bash
python cron_runner.py
```

- Logs like `[CRON] Checking for stale conversations...` should appear every minute.
- Stop with `Ctrl+C`.

## 5. Run continuously in the background

### Option A: `nohup`

```bash
nohup python cron_runner.py > cron.log 2>&1 &
```

### Option B: `screen` or `tmux`

```bash
# Start a new screen session
screen -S cronjob
python cron_runner.py
# Detach: Ctrl+A then D
# Reattach later: screen -r cronjob
```

### Option C: Systemd service (recommended for production)

- Create `/etc/systemd/system/cronjob.service`:

```ini
[Unit]
Description=Ventio Cron Job
After=network.target

[Service]
User=your_user
WorkingDirectory=/path/to/project
ExecStart=/path/to/venv/bin/python cron_runner.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
# Reload systemd and start the service
sudo systemctl daemon-reload
sudo systemctl enable cronjob.service
sudo systemctl start cronjob.service
sudo systemctl status cronjob.service
```

**View live logs**:

```bash
journalctl -u cronjob.service -f
```

- The cron job will now run continuously in the background.
- Any errors or print statements from `cron_runner.py` will appear in the logs above.
